# 角色導入驗收證據

測試必須走本次導入的正式 loader、動畫控制器及場景更新路徑。隔離頁可呼叫同一模組、記錄動畫時間與骨骼姿勢，不能另寫一套成功的控制器充當正式實作證據。失敗注入只用隔離素材、可還原的網路攔截或依賴注入，不改原始素材或正式服務。

| 適用情境 | 操作與可判斷結果 |
|---|---|
| 所有導入 | 實際鏡頭查看比例、腳底、朝向、貼圖及四肢；動作循環數次，確認接縫與滑步。記錄可見問題，不能以「有畫面」通過。 |
| 狀態切換 | 起停、碰撞、快速反向；檢查當前 action、權重及姿勢。只有真正狀態改變才重設；其他動作依本次設定測試完成及中斷。 |
| 暫停／背景 | 經正式暫停入口，對比前後 action 時間、骨骼與角色位置；恢復後時間繼續而無大步跳躍。呼叫 scene 的暫停參數只證明場景層，不能取代瀏覽器隱藏事件或整個遊戲暫停入口。 |
| 多角色 | 同畫面一人移動、一人站立，交換操作；骨骼／action 不共享，刪除一人後其他人正常。多人遊戲另測兩個真正客戶端的輸入與同步；兩個本機 clone 不等於聯網通過。 |
| 既有附件 | 名字、隊伍識別與手持物在起停、轉身、互動仍可辨識；持物姿勢不合適時記錄，不以邏輯可拿取代替視覺驗收。 |
| 非同步 | 延遲載入時離場／重新進入，舊結果不再加入場景；模型或必要貼圖失敗時有明確備援，無逐幀重試與未處理 rejection。缺 clip、骨架不相容須拒絕，不播放錯誤動畫冒充成功。 |
| 手機目標 | 窄視窗檢查畫面、控制及可讀性；實體手機另測觸控、載入及穩定幀時間。記錄裝置、瀏覽器、角色數與測量區間，不從平均 FPS 推論所有手機流暢。 |
| 清理／恢復 | 反覆進出及角色增減後，事件、mixer、動畫迴圈與 GPU 資源按所有權清理；共享資產不能被單一角色 dispose 損壞。 |

每項紀錄：情境、素材／版本、入口、預期、實際、證據位置、狀態。失敗項先修正授權範圍內問題再重測；無裝置或服務時寫阻塞原因及未證明的行為。第三種真實動畫不存在時，可用合成 clip 測映射與單次結束，但須標明不能推論第三份 FBX 相容。

完成報告先寫可用範圍及未解決限制。單一專案成功不等於任意角色／遊戲全面相容；載入安裝、實際採用 Skill、執行與發布分開回報。
